## 自動テスト（vitest 単体）

### 純粋判定 `traceProgress`（合成点列・DOM非依存）
| # | 対象 | 手順 | 期待 |
|---|---|---|---|
| NU1 | `advanceTrace` 順消化 | 直線点列を先頭から順に許容半径内へ | nextIndex/consumed が1つずつ前進 |
| NU2 | `advanceTrace` 飛ばし許容 | lookahead=2 で2つ先だけ通す | frontier がその点+1まで前進 |
| NU3 | `advanceTrace` 逆行不可 | 前進後に手前へ戻す | nextIndex は減らない |
| NU4 | `advanceTrace` 圏外 | どの先読み点も tolerance 超 | 状態不変 |
| NU5 | `isTraceComplete` 完成 | 消化率≥0.85 かつ残り≤lookahead | true |
| NU6 | `isTraceComplete` 未完(率不足) | 消化率<0.85 | false |
| NU7 | `isTraceComplete` 未完(終点未到達) | 中盤だけ密に消化 | false |
| NU8 | `traceRatio` | 途中/全消化 | nextIndex/length に一致 |
| NU9 | `initialTraceState` | 生成 | nextIndex=0・consumed=0 |
| NU10 | 境界（許容半径ちょうど） | distance=tolerance/＋ε | ちょうど=消化・超過=非消化 |
