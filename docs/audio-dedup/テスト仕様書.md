# 出題音声の再利用（オプトイン共有） テスト仕様書

対象: [実装計画.md](./実装計画.md)

## テスト方針

- **自動テスト（vitest）**: 音声パス解決ロジックと、`audio` 参照／実ファイルの整合性
- **自動テスト（Playwright E2E）**: `audio` 指定・未指定の双方で正しいパスになること
- **手動テスト**: 実機での聞こえ方（TTS 内容・タイミング）

受け入れ基準（Definition of Done）:
- `audio` 未指定の問題は従来どおり `/audio/q/<問題ID>.mp3` を使う（**挙動不変**）
- `audio` 指定の問題は `/audio/q/<audio値>.mp3` を使い、正しい読み上げが鳴る
- `audio` を付けた問題の音声は生成されない（参照先を共有する）
- 既存の自動テスト（lint / typecheck / vitest / e2e）がすべてグリーン

---

## 1. 自動テスト（単体）— 音声パス解決

再生側のパス決定は `prompt.audio ?? id` の単純ルール。純粋な分岐として検証する。
（QuizEngine から小関数 `resolveAudioName(problem)` を切り出すとテストしやすい）

| ID | 観点 | 入力 | 期待 |
|----|------|------|------|
| U-01 | 未指定は ID | `audio` 無し、`id="size-003"` | `"size-003"` |
| U-02 | 指定は参照優先 | `audio="size-001"`, `id="size-003"` | `"size-001"` |
| U-03 | 空文字は ID 扱い | `audio=""` | ID にフォールバック（`""` を使わない） |
| U-04 | パス組み立て | `resolve` 結果 `"size-001"` | `/audio/q/size-001.mp3` |

## 2. 自動テスト（統合）— `audio` 参照と資産の整合性

新規: `lib/__tests__/audio-reuse-integrity.test.ts`（全 `content/problems/*.json` を走査）

| ID | 観点 | 期待 |
|----|------|------|
| T-01 | 参照先の存在（データ整合） | すべての `audio` 値が、同カテゴリのいずれかの「`audio` 未指定の問題 ID」に一致する |
| T-02 | 参照先 MP3 の存在 | 各 `audio` 値 `<name>` に対し `public/audio/q/<name>.mp3` が存在する |
| T-03 | 未参照ファイルなし | `public/audio/q` の各 MP3 が「いずれかの問題から使われている」（旧音声の消し忘れ検知） |
| T-04 | 自己参照でない | `audio` 値が自分自身の `id` と一致しない（無意味な指定の検知） |
| T-05 | 実ファイル数 | 実 MP3 数 = `audio` 未指定問題の数（適用後の想定値。count/size/number 適用時は **50**） |

|----|----------|------|

## 6. 手動テスト

| ID | 手順 | 期待 |
|----|------|------|
| M-01 | size を最後まで通す | 全問「おおきい／ちいさい」が正しく読み上げられる（共有音声でズレ・誤読なし） |
| M-02 | count を最後まで通す | 全問「おおい／すくない」が正しく読み上げられる |
| M-03 | number を最後まで通す | 1〜10 が各設問で正しい（`number-011/012` が 2・3 の音を共有再生） |
| M-04 | animal / shape / color | `audio` 未指定のため従来どおり各設問固有の読み上げ |
| M-05 | 問題を 1 問追加し `audio` で既存を参照 | 音声を新規生成せず、既存音声が再生される |

## 7. 適用後チェックリスト（手動）

- [ ] `audio` 未指定カテゴリの挙動が改修前と同一（回帰なし）
- [ ] `audio` 適用問題の再生が参照先音声になっている
- [ ] `audio` を付けた問題の旧 MP3 を整理した（未参照ファイルが残っていない）
- [ ] `content/audio/manifest.json` を**作っていない**（本方式では不要）
- [ ] `npm run lint` / `npm run typecheck` / `npm run test` / `npm run e2e` がグリーン
