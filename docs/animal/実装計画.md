# 実装計画: 新クイズ種目「どうぶつ（animal）」

## 概要
既存の color / shape / number と同じ select-one 方式で、プロンプトで指定された動物の **イラスト画像**を選ばせる新カテゴリ `animal`（表示名「どうぶつ」）を追加する。
判別ユニオン・レンダラ委譲・プール抽出（5問/レッスン）・ノーフェイル進行・ごほうび導線にそのまま乗せる。

- 選択肢の絵は HiggsField（Recraft 4.1 / standard）で生成した統一画風のイラスト12種。`public/images/animals/<animal>.png`（384px・白背景）。
- **音声 MP3 は今回生成しない**（Pro TTS 日次クォータ枯渇のため）。`prompt.say` は記載し、`lib/audio.ts` の playClip が 404 → Web Speech フォールバックで読み上げる。クォータ回復後に `gen-audio` で生成すれば自動で差し替わる。

## 追加 / 変更ファイル
### 新規
- `content/problems/animal.json` … 12問（select-one・choices に `image`）
- `components/quiz/renderers/AnimalChoice.tsx` … 画像選択肢レンダラ（既存レンダラと同シグネチャ）
- `public/images/animals/*.png` … 動物イラスト12枚

### 変更
- `lib/types.ts` … `Category` に `"animal"`、`AnimalChoice { image: string }`、`Problem` 判別ユニオン・`Choice` ユニオンに animal 分岐
- `lib/problems.ts` … `lessonSources` に animal（import 含む）、`validateLesson` に `"animal"` 許可＋`image` 必須検証
- `lib/progress.ts` … `createInitialProgress` と `normalizeProgress` のループ配列に `animal`（型の `Record<Category>` 充足に必須）
- `components/quiz/renderers/index.ts` … `choiceRenderers.animal = AnimalChoice` ＋ re-export
- `components/quiz/renderers/Choice.module.css` … 画像表示クラス（object-fit, サイズ）
- `app/(kid)/home/page.tsx` … `tile-animal` 追加（`/game/animal` へ遷移）
- `app/(kid)/home/home.module.css` … `.animal` ラベル色（`--leaf`）。4タイル折り返し確認
- `app/(kid)/game/[category]/page.tsx` … `VALID_CATEGORIES` に `"animal"`

### 変更不要（自動で機能）
- `QuizEngine.tsx`：`choiceRenderers[lesson.category]` で自動解決
- `scripts/gen-audio.mjs`：`content/problems/*.json` を自動列挙 → animal.json を置くだけで後日の音声生成導線に乗る

## レンダラ設計（AnimalChoice.tsx）
- props は既存と同一: `{ choice, state: "idle"|"right"|"wrong", onSelect }`
- 構造: `<button aria-label={choice.label} data-testid="choice" data-correct data-state onClick>` の中に `<img src={choice.image} alt="" />`（画像は装飾、ラベルは button の aria-label に集約）
- サイズ/タップ領域は既存 `.choice` を継承。画像は `object-fit: contain` で正方表示

## 決定事項
1. 問題形式: 通常12問（「〇〇は どれかな？」）
2. 動物12種: dog/cat/rabbit/bear/elephant/lion/monkey/pig/giraffe/panda/sheep/frog
3. 問題数: 12（1レッスン5問ランダム抽出）
4. ステッカー: 問題ごと `sticker-<animal>`
5. home タイル色: `--leaf`
6. アクセシビリティ: button に `aria-label`=動物名、img は `alt=""`
7. `validateLesson` に animal 用 `image` 必須チェックを追加

## リスク
- `Category` 追加で `Record<Category>` を使う箇所（lessonSources / choiceRenderers / createInitialProgress）は型エラーで検出。`normalizeProgress` の配列・`VALID_CATEGORIES` は実行時値のため手動追加が必須。
- progress 後方互換: 既存 localStorage に animal キーが無くても normalizeProgress が補完（破壊しない）。
- 画像は白背景。タイル表示は白基調のカード見えになる（許容）。後日 background 透過も可能。
